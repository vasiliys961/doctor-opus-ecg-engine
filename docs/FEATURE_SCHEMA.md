# Схема ECG531Input

Машинный контракт колонок: `ecg_engine/feature_columns.py`. Это порядок заголовка `tests/fixtures/another_ecg_features.csv` после отбрасывания `ecg_id`. Список получен из `ecg_web_up` коммита `bfe7c1738baca97f9f501ede25f1716f2aa94cf6` и больше не сортируется.

| Поле | Значение |
| --- | --- |
| Имя | `ECG531Input` |
| Признаков | 531 |
| Версия схемы | `ecg531.v1` |
| Версия модели | `ecg-ensemble-531` |
| Версия препроцессинга | `zscore-train-stats-v1` |
| Коммит источника | `bfe7c1738baca97f9f501ede25f1716f2aa94cf6` |
| Нормализация | `(x - ecg_train_mean.npy) / ecg_train_std.npy` |
| Форма mean и std | `(1, 531)`, `float64` |
| Строка | только индекс 0 |

Первая колонка: `PQ_Int_I`. Последние три: `HA__Global`, `HA__Global_iqr`, `HA__Global_count`. Две последние имеют сохранённые `std = 1` (в обучающей выборке не было разброса).

## Правила чтения

Код в `ecg_engine/schema.py` делает следующее.

- Считает признаками все колонки, кроме точного имени `ecg_id`.
- Сравнивает оставшийся порядок с `FEATURE_COLUMNS` позиционно.
- Берёт первую строку.
- Требует конечное число в каждой из 531 колонок.

Отказ, а не починка, если:

- колонок не 531;
- имя на какой-то позиции другое, даже когда набор тот же;
- есть лишняя колонка;
- колонки не хватает;
- в используемой строке `NaN`, пусто или нечисло;
- в используемой строке `Inf`.

Пропуск не заменяется на `train_mean`. В `ecg_web_up` такая замена была. На полном конечном CSV формула z-score от этого не меняется, поэтому regression на `another_ecg_features.csv` остаётся сравнением той же арифметики. Порченый CSV теперь останавливает инференс.

Несколько строк в файле не усредняются и не прогоняются пакетом. В JSON есть `rows_in_file`, чтобы было видно, что остальные строки не использованы.

## Нормализация

`models/ecg_ensemble/ecg_train_mean.npy` и `ecg_train_std.npy` скопированы байт в байт. Нулей в `std` нет. После проверки конечности:

```text
normalized = (x - mean) / std
```

Дальше вектор приводится к `float32` на CPU. Для MLP форма `(1, 531)`, для CNN и ResNet `(1, 1, 531)`.

Единицы, формулы и происхождение каждого признака. Имена семейств разобраны в `docs/ECG_MODEL_SPEC.md`. Этого недостаточно, чтобы восстановить вектор из raw ECG. Состояние этой задачи: `docs/RAW_TO_531_STATUS.md`.
