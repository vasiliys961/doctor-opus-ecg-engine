# Архитектура doctor-opus-ecg-engine

Шаг 1 фиксирует только левый верхний вход: готовый CSV из 531 колонки и уже обученный ансамбль. Остальные входы обозначены, но не реализованы.

```text
531 CSV ───────────────→ ансамбль MLP + CNN + ResNet1D-18 → 24 score
                           ↑
Raw 12-lead ECG → [экстрактор не доказан] → 531
                           ↑
ECG image ─────────────→ vision Doctor Opus, код ещё не перенесён
```

`raw → 531` имеет статус `NOT YET PROVEN`. См. `docs/RAW_TO_531_STATUS.md`.

## Каталоги сейчас

```text
ecg_engine/          инференс, схема, коды SCP, CLI
models/ecg_ensemble/ веса и mean/std, копия ecg_web_up
tests/fixtures/      публичный CSV ecg_id=513
tests/regression/    сверка с оригинальным скриптом
docs/                аудит и контракты
frontend/            пусто, UI после подтверждения
backend/             пусто, HTTP после подтверждения
```

Движок не импортирует `doctor-opus-global`. Production-репозиторий не менялся.

## Контракт результата CLI

```bash
python -m ecg_engine.predict tests/fixtures/another_ecg_features.csv
```

`predictions` — среднее трёх сигмоид, ключи в порядке индексов модели. `heads` хранит MLP, CNN и ResNet по отдельности. Порога нет: число — model score, не калиброванная вероятность.

Модели грузятся на CPU и в процессе держатся в кэше. Отдельного сервера на этом шаге нет, поэтому «один раз на процесс» относится к повторным вызовам `predict_csv` внутри одного интерпретатора.

## Что переносить из Doctor Opus позже

Только ECG-контур, по `docs/DOCTOR_OPUS_ECG_AUDIT.md`: страница изображения, линейка, ручная маска кистью, критерии наблюдателя, короткое функциональное заключение.

Решения, которые уже зафиксированы и в шаг 1 кодом не вошли:

- `preserve_original_image = true` по умолчанию. Чёрные поля по краям из production-препроцессинга для ЭКГ не включаются сами.
- Линейка при переносе должна использовать 25 и 50 мм/с и получить измерение напряжения. Сейчас в Opus скорость на формулу не влияет, вольтажа нет.
- PDF закладывается как отдельный вход image-канала. Текущая страница `/ecg` его не принимает, поэтому поддержки в этом репозитории ещё нет.
- USB-модуль Opus не считается входом raw 12-lead. Это одноканальная картинка.

Vision, fusion и вторая raw-сеть ждут отдельного шага.
